# Art Explorer

A Flutter app for browsing the Art Institute of Chicago's public collection — browse thousands of artworks and save favourites to a personal collection that syncs across devices.

*Built in public as a portfolio piece, demonstrating BLoC, REST APIs, Firebase Auth, and Firestore.*

## Tech Stack

| Layer | Choice | Notes |
|---|---|---|
| Language | Dart / Flutter | iOS & Android |
| State management | BLoC | One bloc per domain — `AuthBloc`, `ArtworkBloc`, `CollectionBloc` |
| Data source | AIC Public API (REST) | CC0, no API key required — requests send an `AIC-User-Agent` header identifying the app, per AIC's guidance, to avoid Cloudflare rate-limiting |
| Auth | Firebase Auth · Google Sign-In | Email/password and Google Sign-In |
| Database | Firestore | Per-user saved collections, cross-device sync — locked down by `firestore.rules` |

## Architecture

Strict BLoC + Repository — no business logic in the UI layer. Each bloc owns one domain and emits states the UI rebuilds from; repositories own all API and Firestore access.

```
UI (screens / widgets)
  ↓  events
BLoC          AuthBloc · ArtworkBloc · CollectionBloc
  ↓  calls
Repository    ArtRepository (AIC API) · AuthRepository (Firebase) · CollectionRepository (Firestore)
  ↓
Models        plain Dart data classes (Artwork)
```

`CollectionBloc` also subscribes directly to `AuthBloc`'s state stream — it auto-fires `LoadCollection` on sign-in and `ClearCollection` on sign-out, independent of any UI action.

The app launches straight into Browse with no forced auth wall. Tapping Save while signed out opens a modal `AuthBottomSheet` over the current screen; on successful sign-in the sheet dismisses and the save completes automatically.

Firestore access is restricted via `firestore.rules`, committed at the repo root: each user can only read/write their own `users/{uid}/savedArtworks` subcollection.

## Getting Started

### Prerequisites

- Flutter 3.x / Dart 3.x
- VS Code with the [Flutter extension](https://marketplace.visualstudio.com/items?itemName=Dart-Code.flutter)
- Android SDK via Android Studio (emulator / device builds)
- Xcode (macOS only — required for iOS simulator and device builds)
- A Firebase project (config files are not committed — see below)

### Firebase setup

1. Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
2. Enable **Email/Password** and **Google Sign-In** under Authentication
3. Enable **Firestore**
4. Run `flutterfire configure` to generate `lib/firebase_options.dart`
5. Download `google-services.json` from the Firebase console and place it in `android/app/`
6. Download `GoogleService-Info.plist` from the Firebase console and place it in `ios/Runner/`
7. For Google Sign-In on Android: add the SHA-1 fingerprint to your Android app in the Firebase console
8. Deploy `firestore.rules` (`firebase deploy --only firestore:rules`) so saved collections are locked to their owner

### Clone & run

```bash
git clone https://github.com/eomapps/artexplorer_flutter.git
cd artexplorer_flutter
flutter pub get
flutter run
```
